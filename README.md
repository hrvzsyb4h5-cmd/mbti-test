# MBTI 人格进化测试

一个纯前端的 MBTI 16 型人格深度测试单页应用，60 道题、约 8 分钟，即时生成包含进化阶位、8 维属性图谱、灵魂伴侣契合度、认知功能、天赋职业与成长路线的完整报告。

## 特性

- 16 型人格识别 + 低阶 / 中阶 / 高阶三阶进化位判定
- 8 维属性雷达图与分值条（脑力在线、自我接纳、情绪免疫力等）
- 灵魂伴侣契合度与认知四功能拆解
- 天赋职业方向与阶位成长路线
- 支持生成分享海报、URL 参数直达结果（`?type=ENFP&stage=high|mid|low`）
- 纯静态页面，无后端、无依赖，打开即玩

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动任意静态服务器：

```bash
python3 -m http.server 8000
```

## 部署

本仓库为纯静态站点，已开启 GitHub Pages：推送到 `main` 分支后，通过仓库 Settings → Pages 发布，访问地址为 `https://<用户名>.github.io/<仓库名>/`。
